# NOVA — Smart Digital Wallet

A polished frontend-only personal finance / digital wallet demo.

## How to run

1. Open this folder in VS Code.
2. Make sure these 3 files are in the same folder:
   - `index.html`
   - `style.css`
   - `script.js`
3. Right-click `index.html`.
4. Choose **Open with Live Server** if you have the VS Code Live Server extension.
5. Or simply double-click `index.html` to open it in a browser.

## Important

This is a portfolio/demo project. It does not connect to a real bank, UPI, card network, or payment gateway. Add-money and send-money actions only change data inside the browser.
